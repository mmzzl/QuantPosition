# Feature Specification: 板块热力图

**Feature Branch**: `005-sector-heatmap`  
**Created**: 2026-05-16  
**Status**: Draft  
**Input**: User description: 基于MongoDB中的K线数据实现板块热力图，支持最近24小时、7天、30天和自定义日期筛选，点击板块名称跳转到板块股票列表，每只股票后面显示K线按钮，点击可查看K线图

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 查看板块热力图 (Priority: P1)

用户进入热力图页面后，系统根据选定的时间范围（24小时/7天/30天/自定义日期）计算各板块的涨跌幅，并以热力图形式展示。颜色深浅表示涨跌幅度，红色表示上涨，绿色表示下跌。

**Why this priority**: 这是核心功能，用户通过热力图快速了解哪些板块表现强势或弱势，是投资决策的重要参考。

**Independent Test**: 用户打开热力图页面，选择时间范围，系统正确显示各板块的颜色和涨跌幅数据。

**Acceptance Scenarios**:

1. **Given** 用户进入热力图页面，**When** 选择"最近24小时"，**Then** 显示各板块24小时内的涨跌幅热力图
2. **Given** 用户查看热力图，**When** 板块上涨，**Then** 该板块显示为红色，颜色深浅与涨幅成正比
3. **Given** 用户查看热力图，**When** 板块下跌，**Then** 该板块显示为绿色，颜色深浅与跌幅成正比
4. **Given** 用户选择"自定义日期"，**When** 输入起始和结束日期，**Then** 显示该时间段内的板块涨跌幅

---

### User Story 2 - 查看板块股票列表 (Priority: P2)

用户在热力图中点击某个板块名称，跳转到该板块的股票列表页面，显示该板块内所有股票的详细信息（股票代码、名称、涨跌幅、成交量等）。

**Why this priority**: 用户了解板块整体表现后，需要进一步查看板块内个股表现，找出领涨或领跌的股票。

**Independent Test**: 用户点击热力图中的板块，系统正确跳转到股票列表页面并显示该板块所有股票。

**Acceptance Scenarios**:

1. **Given** 用户在热力图页面，**When** 点击某个板块名称，**Then** 跳转到该板块的股票列表页面
2. **Given** 用户在板块股票列表页面，**Then** 显示该板块内所有股票的代码、名称、涨跌幅、成交量等信息

---

### User Story 3 - 查看个股K线图 (Priority: P3)

用户在板块股票列表中，每只股票后面有一个"K线"按钮，点击后弹出该股票的K线图，展示指定时间范围内的价格走势。

**Why this priority**: 用户需要了解个股的历史走势，K线图是最直观的技术分析工具。

**Independent Test**: 用户在股票列表中点击K线按钮，系统正确显示该股票的K线图。

**Acceptance Scenarios**:

1. **Given** 用户在板块股票列表页面，**When** 点击某只股票的"K线"按钮，**Then** 弹出该股票的K线图
2. **Given** 用户查看K线图，**Then** 显示指定时间范围内的开盘价、收盘价、最高价、最低价

---

### Edge Cases

- 当某板块在选定时间内无交易数据时，热力图显示为灰色或"无数据"
- 当用户选择的自定义日期范围内无数据时，提示用户调整日期范围
- 当K线数据不完整时，K线图显示已有数据并标注数据缺失区间
- 网络请求失败时，显示错误提示并允许用户重试

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 从MongoDB中读取K线数据，按板块聚合计算涨跌幅
- **FR-002**: 系统 MUST 支持时间筛选条件：最近24小时、最近7天、最近30天、自定义日期范围
- **FR-003**: 系统 MUST 以热力图形式展示板块数据，颜色映射涨跌幅度
- **FR-004**: 用户 MUST 能够点击板块名称跳转到该板块的股票列表
- **FR-005**: 股票列表 MUST 显示每只股票的代码、名称、涨跌幅、成交量等关键信息
- **FR-006**: 每只股票后面 MUST 显示"K线"按钮，点击后展示该股票的K线图
- **FR-007**: K线图 MUST 显示开盘价、收盘价、最高价、最低价（OHLC）
- **FR-008**: 系统 MUST 将CSV中的板块-股票映射数据导入MongoDB，避免每次读取CSV
- **FR-009**: 系统 MUST 在页面加载时显示加载状态，数据加载完成后展示内容

### Key Entities

- **板块（Sector）**: 股票的行业或概念分类，包含板块名称、板块代码、成分股列表
- **K线数据（K-Line Data）**: 股票的价格数据，包含日期、开盘价、收盘价、最高价、最低价、成交量
- **板块-股票映射**: 记录每只股票所属的板块，用于聚合计算板块涨跌幅

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可以在3秒内加载完成热力图数据（100个板块以内）
- **SC-002**: 90%的用户可以在首次使用时成功查看热力图并筛选时间范围
- **SC-003**: 点击板块后，股票列表页面在2秒内加载完成
- **SC-004**: K线图可以在1秒内渲染完成，支持缩放和拖拽交互

## Assumptions

- MongoDB中已存在K线数据，包含股票代码、日期、OHLCV等字段
- CSV文件包含完整的板块-股票映射关系，数据格式稳定
- 用户主要使用桌面浏览器访问，热力图以桌面端体验为主
- 板块分类使用中国证监会行业分类标准
- 热力图颜色方案：红色系表示上涨，绿色系表示下跌，符合中国股市习惯
